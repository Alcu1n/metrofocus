# 设计说明

## 方向

“夜行地铁 × 随身通行证”。2026-09-30 用户选择 C 方案，并确认车站与票夹的迁移效果。深墨黑底承载导航和说明；奶油纸色承载未出发的任务表单与已经到站的时间存根。线路色负责身份，票面文字、撕线及印章负责信息分区与状态。

选定方案与具体组件契约见 [C 设计规范](prototypes/station-tournament-v1/C-DESIGN-CONTRACT.md)。

轨道、列车、M 标志、条码及纸票轮廓由原生 SwiftUI Path / Canvas 绘制。交互文字和控件均为原生视图；没有把设计图当作界面背景。系统标签栏、表单、权限弹窗和分享面板保留 iOS 行为。

## 设计系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景 / 表面 | #0A0E11 / #151B20 | 全局层次 |
| 主文字 / 次文字 | #F1F2EC / #A0ADAE | 可读性 |
| 写作 / 代码 | #FF4685 / #64D89A | 线路识别 |
| 阅读 / 生活 | #E8C45F / #85C9F1 | 线路识别 |
| 休息 | #E5BF59 | 站台等待 |
| 票纸 / 票墨 | #EDE7D5 / #23362D | 实体存根 |

车站与票夹页面边距 22 pt，票面内距 21 pt、列表票根 18 pt，纸票圆角 13 pt。主要行动高至少 56 pt，图标点击区 44 pt。标题和内容使用系统字体与 Dynamic Type，关键数字使用可缩放字号及等宽数字。常规字号下三个预设班次完整并排，辅助字号改为纵向；线路选择改为两列。总专注时长在辅助字号下保留于可滚动票面，固定出发区只保留主操作。运行舱已有的大字号布局和手势规则继续保留。

## 纸票材质 · 2026-10-01

按用户新增的拟物要求，票纸增加轻微的机械凹印与纸板厚度：任务、时间和分钟数字使用上沿暗部与下沿细亮边；虚线为暗槽加下缘纸色高光；轮廓沿底部叠加 1 / 2 pt 暖灰纸层，侧孔和打孔保持同一几何形状。细纤维为固定 Canvas 纹理，不添加运动或图片依赖。车站、票夹及详情共用纸面和凹刻撕线；文字保留原有字号、颜色语义、布局与辅助功能。

## 关键页面

- **车站**：线路选择位于纸票上方；任务、三个带段数的班次、行程摘要与“尚未发车”标识在同一票面。出发摘要在固定按钮上方；空任务在票面内提示并聚焦输入。自定义班次继续通过原有编排入口配置。
- **票夹**：按抵达日期分组；每张存根展示线路、抵达时刻、班次代码、任务、专注分钟和到站/验票状态。总量只计算真实已保存票根。空状态保留去车站入口，不显示示例数据。
- **运行舱**：倒计时是第一视觉层级；曲线轨道只表达当前区间，区间数量与已专注时间单独显示，避免将装饰节点误读成完成进度。
- **休息**：轨道换为暖色。休息到期停在站台，主按钮明确“继续发车”，不让无人值守的时间变成专注记录。
- **车票**：统一纸色、墨色、撕线、侧孔、打孔和印章共同表达留存。侧孔位置取实际撕线布局锚点，中英文内容变化不会使二者错位。倾斜仅在当前票根页前台启用，降低动态效果时关闭。
- **路网**：有时间才铺实线；未来两站是低对比虚线，空账户没有伪造成就。站点按固定序号增长，长线路分段浏览，不以六小时之类的上限停止绘制。

## 评审与改进

对真实模拟器截图进行独立评审后，修正了首页班次卡片被底部行动区截断、品牌文字压缩、运行舱轨道节点含义不明确、票面侧孔与撕线错位、线路标识辨识度及路网成长容量。第二轮补齐了任务输入提示的对比度和班次整卡点击区域；独立复核确认标准中文运行舱和票根没有可见重叠、截断或状态歧义。

评价依据是截图中的层级、比例、排版、状态一致性和真实交互。未将“获奖级”作为可证明的结论；保留真实截图、测试录像和验收限制供继续审阅。

最后一轮 375×667 pt 最大 Dynamic Type 独立截图复核，倒计时、顶部操作和底部暂停／结束均完整可读。相同尺寸的真实交互复验通过暂停、恢复和确认结束；这不替代真实 VoiceOver 手势验收。
