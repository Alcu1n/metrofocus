# 设计说明

## 方向

“夜行地铁 × 实体硬卡车票”。主画面用深墨黑底、大号等宽数字、有限的线路色和明确的交通信息层级，完成后以奶油色车票形成一次有意义的材质与情绪转换。

轨道、列车、M 标志、条码及票纸纹理由原生 SwiftUI Path / Canvas 绘制。交互文字和控件均为原生视图；没有把设计图当作界面背景。系统标签栏、表单、权限弹窗和分享面板保留 iOS 行为。

## 设计系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景 / 表面 | #0A0E11 / #151B20 | 全局层次 |
| 主文字 / 次文字 | #F1F2EC / #A0ADAE | 可读性 |
| 写作 / 代码 | #FF4685 / #64D89A | 线路识别 |
| 阅读 / 生活 | #E8C45F / #85C9F1 | 线路识别 |
| 休息 | #E5BF59 | 站台等待 |
| 票纸 / 票墨 | #EDE7D5 / #23362D | 实体存根 |

边距以 24–27 pt 为主，主要行动高至少 56 pt，图标点击区 44 pt。正文使用系统文字样式，数字使用圆角等宽数字，交通辅助信息使用等宽字体。大字号通过滚动保留行动入口；无障碍字号的运行舱先显示计时，任务与抵达信息改为纵排，主要操作使用简短纯文字。线路编号底色随字号增长，辅助字号班次卡加宽至 290 pt，保留横向浏览；主要按钮的整个可见背景均响应点击。

## 关键页面

- **车站**：任务目的地和线路在同一张卡片内，横向班次列显示单段时长、段数，发车按钮下显示总投入。首页选择第三张班次允许水平滚动。
- **运行舱**：倒计时是第一视觉层级；曲线轨道只表达当前区间，区间数量与已专注时间单独显示，避免将装饰节点误读成完成进度。
- **休息**：轨道换为暖色。休息到期停在站台，主按钮明确“继续发车”，不让无人值守的时间变成专注记录。
- **车票**：纸纹、撕线、侧孔、打孔和印章共同表达留存。侧孔位置取实际撕线布局锚点，中英文内容变化不会使二者错位。倾斜仅在当前票根页前台启用，降低动态效果时关闭。
- **路网**：有时间才铺实线；未来两站是低对比虚线，空账户没有伪造成就。站点按固定序号增长，长线路分段浏览，不以六小时之类的上限停止绘制。

## 评审与改进

对真实模拟器截图进行独立评审后，修正了首页班次卡片被底部行动区截断、品牌文字压缩、运行舱轨道节点含义不明确、票面侧孔与撕线错位、线路标识辨识度及路网成长容量。第二轮补齐了任务输入提示的对比度和班次整卡点击区域；独立复核确认标准中文运行舱和票根没有可见重叠、截断或状态歧义。

评价依据是截图中的层级、比例、排版、状态一致性和真实交互。未将“获奖级”作为可证明的结论；保留真实截图、测试录像和验收限制供继续审阅。

最后一轮 375×667 pt 最大 Dynamic Type 独立截图复核，倒计时、顶部操作和底部暂停／结束均完整可读。相同尺寸的真实交互复验通过暂停、恢复和确认结束；这不替代真实 VoiceOver 手势验收。
