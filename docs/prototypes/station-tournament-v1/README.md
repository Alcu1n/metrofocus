## 共同题目

- 平台：iOS App 的浏览器视觉与交互原型。
- 首要任务：填写这一程要完成的任务、选择线路和班次、准备出发。
- 沿用：MetroFocus 夜行地铁、四条任务线路、实体票感、30 秒候车准备与既有班次规则。
- 样例：写完第一章 / 写作线 / 微步短驳 15 分钟 × 1 / 累计 0 分钟。三案共享同一份输入状态，语言可切换。
- 覆盖组件：任务输入、四线路选择、三种班次、自定义行程底部表单、固定出发区、底部导航、设置开关与空任务错误。
- 主对比视口：402 × 874 CSS px；补充检查 375 × 667。浏览器模拟，非原生设备验收。

## 三案差异

| 维度 | A · 站台导视 | B · 发车时刻表 | C · 随身通行证 |
| --- | --- | --- | --- |
| 阅读顺序 | 目的地标题 → 路线图中的任务 → 横向班次 | 任务 → 线路 → 纵向班次对比 | 线路 → 票面任务与班次 → 票根摘要 |
| 版式与密度 | 分组卡片、连续路线、横向选择 | 对齐表格、分隔线、逐行读取 | 一张浅色纸票、字段与虚线分区 |
| 字体层级 | 33 px 标题 / 38 px 班次数字 | 27 px 标题 / 26 px 任务 / 35 px 班次数字 | 28 px 标题 / 25 px 任务 / 32 px 班次数字 |
| 视觉语言 | 线路粉色、列车示意、圆角深色卡 | 黑白层级、线色细节、选中行 | 奶油色票面、深绿墨色、未发车印章 |
| 优势 | 最接近现有地铁身份，路线有明确作用 | 开始任务与比较班次最直接 | 出发和到站票夹产生视觉呼应 |
| 代价 | 图形占用更多纵向空间 | 情绪装饰较少 | 浅色票面存在感更强 |

共同规则：出发入口固定；中间内容可滚动；班次均包含区间数信息；触控按钮至少 44 CSS px 高；不把原型的倒计时样张当作实际运行引擎。

## 打开预览

从仓库根目录运行：

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory docs/prototypes/station-tournament-v1
```

打开 <http://127.0.0.1:8768/index.html>。可并排查看、单案切换、切换语言、输入长任务或查看空任务提示。键盘左右键切换单案，输入时不抢占光标。弹层支持 Escape 取消和 Tab 焦点循环。

独立方案地址：`?variant=A&view=single`，B/C 同理。`capture=1` 仅隐藏对比工具以导出画面。

“暂选”只在原型中做提示；最终选择以对话中的用户答复为准，不会写入 App 或替用户授权。
